# 合规与离线边界

## 1. 离线承诺

运行期只允许访问本机回环地址：

- mock 标讯门户：默认 `http://127.0.0.1:5810`
- 只读复核台：默认 `http://127.0.0.1:5811`
- 允许的 host：`127.0.0.1`、`localhost`、`::1`

不存在“开关”可以放行公网地址。`allowed_hosts` 中的每一项和 `base_url` 均经过：

1. URL scheme 必须是 `http` 或 `https`。
2. 禁止 URL 内嵌用户名和密码。
3. host 必须位于显式白名单。
4. host 必须是 loopback：IP 的 `is_loopback` 为真，或名称严格等于 `localhost`。

校验发生在 `requests.Session.get` 之前。非 loopback 地址被拒绝时，`SafeFetcher` 会触发 `FETCH_BLOCKED` 审计事件，不会建立连接。

`SafeFetcher` 还采取以下措施：

- `allow_redirects=False`，任何 3xx 都拒绝，避免 Location 将请求带到外部。
- `Session.trust_env=False`，不继承 `HTTP_PROXY`、`HTTPS_PROXY` 等环境配置。
- 只发送本地标识 `tender-anchor-local/1.0`，不伪造浏览器 User-Agent。
- 限制响应体大小并校验字符集，防止异常内容破坏解析。

## 2. 数据合成声明

仓库内所有采购单位、代理机构、地区、项目、公告编号、供应商、附件内容均属于虚构演示数据。页面和 README 明确标注“示例”“虚构”“合成”。

- 未使用真实公司、机构、人名、手机号、邮箱、账号、密钥或证书。
- 未包含真实采购公告正文或真实附件。
- 测试中的非 loopback 地址使用文档保留网段（如 `203.0.113.10`），仅用于验证拒绝路径，不会发起请求。
- mock 页面不包含外部图片、字体、脚本、样式或统计设施。
- 附件是本地生成的合成文本/CSV。

若将该工程复用于真实数据，必须重新进行法律、隐私和授权评估；本仓库不提供此类授权或合规依据。

## 3. 网络与采集行为

系统不做：

- 登录、会话伪造、Cookie 复用、账号注册；
- 验证码识别或绕过；
- 反爬对抗、限速规避、代理池、指纹伪装；
- 真实站点探测、并发压力测试；
- 远程代码、脚本或浏览器执行；
- 从互联网下载模型、词典或 NLP 资源。

系统只做本机 mock 门户的串行 GET：

- 列表页、详情页、附件。
- 明确的超时与最大响应体。
- 失败不重试风暴；每个目标在单次运行中按流程处理一次。
- 保留稳定原因码与运行错误列表。

## 4. 本地数据与路径安全

- 数据库、原始 HTML、附件、导出、报告均写入用户选定的数据目录。
- 所有动态输出路径经 `ensure_within` 复核；`..` 或绝对路径不能越界。
- 附件文件名先转为安全 basename，不允许目录分隔符、控制字符或危险尾随字符。
- SQLite 查询使用参数绑定；导出与页面转义动态文本。
- 原始 HTML 可能包含不可信内容，复核台只显示经过 HTML 转义的数据，不把原始 HTML 嵌入页面。
- 原始 HTML 不通过 Web 路由直接提供下载。

示例数据目录：

- `data/`：手工采集默认目录。
- `data_demo/`：演示默认目录。

运行产物不应提交到版本控制；仅保留 `.gitkeep` 占位。

## 5. 只读复核台

复核台的安全边界：

- 仅绑定 `127.0.0.1`，没有绑定公网地址的参数。
- SQLite 以 `mode=ro` URI 打开，并执行 `PRAGMA query_only=ON`。
- 只定义 GET 路由；没有写入、删除、重载、配置修改接口。
- 响应头设置：
  - `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; form-action 'self'`
  - `X-Content-Type-Options: nosniff`
  - `X-Frame-Options: DENY`
  - `Cache-Control: no-store`
- 导出下载只读取数据目录下固定的 `exports/notices.json` 与 `exports/notices.csv`。
- 页面不引用 CDN、外部字体、外部图片、脚本或 iframe。

复核台不是多用户系统，不提供身份认证。它假设运行在单机开发环境；不要把端口暴露到局域网或公网。

Mock 门户同样只绑定 `127.0.0.1`，并在请求处理前检查远端地址必须为 loopback。

## 6. 密钥与敏感信息

仓库不包含：

- API key、访问令牌、Cookie、账号、密码；
- 私钥、证书、签名文件；
- 外部服务端点、邮件地址、电话号码；
- 生产数据库连接字符串。

配置中的 URL 只允许 loopback。运行日志、审计事件和导出的 URL 也只会是 loopback 地址。

## 7. 审计与可追溯

- 非 loopback、重定向、HTTP 错误等网络拒绝事件写入 `audit_events`。
- 每次运行有唯一 `run_id`，记录状态、页数、公告/附件统计、错误列表。
- 每条公告保存来源 URL、响应 SHA-256、首次/最近运行与版本号。
- 原始详情 HTML 按哈希留档；列表 HTML 也留档并记录审计路径。
- 字段保存原始值、规范化值、抽取器和选择器。
- 附件保存 URL、状态、错误码、内容哈希、大小和相对路径。

## 8. 依赖与离线准备

运行依赖为常见本机 Python 包：

- Flask 3.x
- requests
- BeautifulSoup4 + soupsieve
- PyYAML
- pytest（测试）

项目不依赖浏览器二进制、GPU、外部数据库、云服务或需要联网下载的模型。若目标机器完全断网，请提前在可联网环境准备 wheel 包，再在离线环境安装；安装完成后，运行与测试均不需要网络。
